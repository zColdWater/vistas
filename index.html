Every address
is a place.

Paste any wallet address (Ethereum, Base, Solana, Bitcoin) or any text. Vistas draws it as a small landscape that is always the same for that address and different for every other one. Use it as an avatar, or as a quick visual check before you send money.

Nothing leaves your browser: no network requests, no tracking. The picture is drawn on this page.

Check before you send

Address poisoning works because wallets shorten addresses: two different addresses can both show up as 0x7C1F…78aD. Scammers send you a tiny transfer from a look-alike address and hope you copy it from your history. Two look-alike addresses get two completely different vistas. Paste the address you meant and the one you are about to pay.

Paste two addresses to compare them.

A vista is a quick visual check, not a security guarantee. Always confirm the full address and the network in your wallet before you send.

For developers

A drop-in replacement for blockies or jazzicon, for any dApp, wallet, explorer or forum that shows addresses.

  • One file, zero dependencies
  • ~22 KB unminified
  • SVG out, crisp at 16 px or 1600 px
  • Deterministic and frozen as vistas-v1
  • Browser and Node
  • MIT

Plain HTML: put data-vista on any element or image.

<script src="https://zcoldwater.github.io/vistas/vistas.js"></script>

<img data-vista="0x7C1F…" data-vista-size="40"
     data-vista-shape="circle" alt="">

<script>Vistas.hydrate()</script>

JavaScript: get an SVG string or a data URI.

const svg = Vistas.svg(address, {
  size: 64,          // px, or 'auto'
  shape: 'circle'    // 'square' | 'rounded' | 'circle'
});
img.src = Vistas.dataUri(address, { size: 64 });
Vistas.describe(address).name  // "Lucid Meadows"

EVM addresses are matched case-insensitively (checksum casing does not change the picture), as are bech32 Bitcoin addresses and .eth names. Solana and everything else is used exactly as typed. Source and docs: github.com/zColdWater/vistas.
